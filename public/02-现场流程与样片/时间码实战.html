想要一键合板？索尼A7S3时间码使用教程来了

（　👍 206）

来源：小红书「酷卡学院 Academy KK」

前期

  • 索尼 A7S3 仅支持通过音频方式（Audio TC）从音频口输入时间码。
  • 准备好 3.5 对 3.5 的音频线，连接时码器 3.5 接口和相机音频输入接口（注意：非耳机监听口）。
  • 将谛听（DEITY TC-1）时码器设置为 A-Out 即声音输出（也可在手机 APP Sidus Audio 进行设置），并固定至相机热靴接口。
  • 确定拍摄帧率，保证时码器和项目帧率一致；如果项目帧率为 50/60 帧，则时码器需要设置为 25/30 帧（成倍数关系）。
  • 在相机设置中将音频增益调至合适大小：双声道音频中，电平高的为时码信号，电平低的为参考声。

后期

  • 使用达芬奇提取音频时间码：右键素材 → Update Timecode from Audio Track；
  • 或使用章鱼软件批量将时间码写入文件（Original media with embedded TC，Pass Through Original）。
  • 注意保留好原始文件，音频时码会覆盖文件时码。

索尼a7s3支持时间码输入

（2024-03-28　👍 26）

  • 索尼 A7S3 ver3.00 固件支持通过 Micro USB（multi/micro USB 终端）输入时间码，无需再用音频方式输入时码。
  • 连接方式和 FX3/FX30 一致，使用谛听 C23 时码线即可。
  • 注意：需单独购买专用适配器电缆；DCI 4K 与 24.00p 录制需安装免费许可证（可用性因国家/地区而异）。

Codex读卡器低性能提示如何更新固件？（65f66a3c，3 图）

  • 部分 Codex 读卡器连接电脑时提示"性能降低"：较老型号与 M1 芯片兼容性差，需更新固件。
  • 不兼容型号（macOS 12.4 或之后版本）：
    • Rev A（序列号 01052271 之前）：限 600MB/s
    • Rev B（01052272–01054999）：限 600MB/s，更新固件后满速
    • Rev C（01055000 之后）：满速
  • 序列号在读卡器底部铭牌（MODEL CX.0001005 旁 SERIAL NO.）。
  • 更新方法：官网下载安装 Codex Device Manager → 连接卡和读卡器 → 点齿轮图标 → Update Firmware → 固件更新工具点 Run → 完成后重新插拔设备，齿轮感叹号消失，速度提升。

时码口故障🧑‍🔧时间码偏移如何修改？

（2024-05-23　👍 66）

💻这次拍摄使用的是Alexa 35，时码口故障，无法使用时码器同步，换新机器前的素材时间码有偏移。广告拍摄不打板，基本的处理方法是，使用达芬奇根据口型查看视频偏移量，使用qtchange修改时间码。

💰qtchange为付费软件，需要序列号可联系我们购买。
