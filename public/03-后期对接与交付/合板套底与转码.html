合板、套底与转码

来源：小红书「酷卡学院 Academy KK」实战笔记汇编（多机位合板（达芬奇/Pr）、代理生成、套底问题与特殊素材转码。），2026-11-01 采集整理。

达芬奇如何进行多机位快速合板🔜

（　👍 821）

（源时间码合板，非多机位片段）相对 Pr，达芬奇可根据源时间码自动将片段导入时间线，删除空隙即完成合板。

  1. 将视频素材（代理）和音频素材导入媒体池（按机位/录音分文件夹，如 A001R1NF、B001R49C、C001R16P、240131）。
  2. 右键音频新建时间线：三机拍摄选音频新建时间线，视频轨道数量选 3（起始时间码如 11:00:00:00）。
  3. 逐机位导入视频：激活轨道 1 → 全选 A 机素材 → 右键"使用时间码将所选片段插入时间线"；轨道 2 导 B 机，轨道 3 导 C 机。
  4. 删除所有空隙：全选素材 →"编辑"→"删除空隙"→ 得到合板时间线。
  5. ⚠️ 该方法仅适用于达芬奇内部：导出 XML 进 Pr 会出现所有轨道音频波形一致的情况（"达芬奇合板只能达芬奇用，Pr 合板 Pr 和达芬奇都能用"）。

综艺纪录片多机位拍摄如何快速合板🔜

（　👍 1051）

除章鱼合板软件外，一般软件很难批量合板多机位素材。本文用 Pr 创建单机位源序列 + 时间线合并的方式合板：有一定学习难度，但灵活性强、与其他剪辑软件交接问题少。无论用什么方式合板，前期时间码正确同步都是重中之重。

  1. 导入素材：视频（代理）+ 音频（Poly 格式）导入 Pr，素材须有正确时间码（按机位分文件夹）。
  2. 创建单机视频时间线：选中某机全部素材 → 右键"创建多机位源序列…" → 勾选"创建单个多机位源序列"（轨道分配：摄像机标签）→ 确定后改名为"A机"。右键时间线"在时间轴内打开"（或 Cmd+双击），反斜杠缩放至时间轴长度——素材按时间码排列，中间有空隙。同样方法建 B 机、C 机时间线。
  3. 创建音频时间线：方法与视频类似，但需选择一条视频 + 所有音频一起创建。打开音频时间线，删除空隙和视频，只留音频轨。
  4. 合并总时间线：复制 C 机时间线建立【总时间线】（只能复制创建）→ 打开后 Cmd+A 全选、Option+上 把 C 机素材移到轨道 3；打开 A 机时间线找到起始时间（如 11:09:04:21）复制全部素材 → 总时间线跳转到该时间码 → 粘贴到轨道 1；B 机同理（锁定轨道 1 后粘贴到轨道 2）；音频同理粘贴。
  5. 所有素材按拍摄时间正确同步。要无空隙时间线：Pr 里"序列"→"封闭间隙"，即得三机位声画合板时间线。
  6. 交接：文件 → 导出 → Final Cut Pro XML，交剪辑师。

FCPX剪辑索尼素材套底失败解决方法

（　👍 158）

由于FCPX无法正确识别索尼MP4封装文件，原素材时码会被重置为00:00:00:00，导致在达芬奇中无法成功套底。需要在达芬奇中，通过csv将所有原素材时码统一修改为00:00:00:00，即可成功套底。 . 正确的时间码对调色套底十分重要，部分索尼机型如A7M4，FX3拍摄素材为MP4封装，剪辑软件如FCPX可能无法正确识别时间码，导致后期套底失败，无法链接原素材。 . MP4素材可使用Editready等软件转为MOV封装，以避免时码不识别或错误识别。

50帧MP4素材注意事项

（　👍 55）

MP4封装：不支持超过30帧的时间码 MOV封装：支持超过30帧的时间码 所以理论上拍摄50帧项目时，准确时间码应该是20:24:20:48，翻倍是比较合理的做法。

关于Prores RAW你需要了解的事

（2024-04-14　👍 156）

  • ProRes RAW 是 Apple 推出的压缩 RAW 格式：既有 RAW 画质，又有 ProRes 的文件体积。但常见后期软件支持不完善，使用时需先转码为 DNG 或其他 ProRes 文件再进后期流程。
  • 什么情况会遇到：支持 PRAW 的相机不多；DIT/制作方最常见的是汽车广告航拍用悟3拍 PRAW（最高 8K 75fps）。
  • 素材可在 DJI 官网下载悟3样片练习。
  • 为什么不能直接用：达芬奇不支持 PRAW 导入；达芬奇和 Silverstack 都不支持 PRAW 转码生成代理。使用 PRAW 需先转成中间文件（供调色）和代理文件（供剪辑）。
  • 转码软件：Assimilate Scratch、Compressor、Editready；推荐 Editready（易上手，拖入素材选预设即转；付费，基础版 99 美元授权两台电脑）。
  • 转码格式选择：先转 422 Proxy 上传网盘供剪辑，再将 PRAW 转 422 作为调色大档。PRAW 码率与 422 相当；如需转 DNG 或 4444，务必考虑存储空间是否足够！

（2024-02-13　👍 325）

快拍慢放是升格，慢拍快放是降格，常拍常放声画齐，慢拍补帧王家卫。

专业影视制作流程的秘密⁉️离线剪辑是什么

（2024-02-12　👍 172）

在当今影视制作流程中，许多剪辑师已经习惯使用原始素材进行剪辑，我们称之为在线剪辑（Online）。而在专业制作中，剪辑师会使用代理素材（Proxy）进行剪辑，我们称之为离线剪辑（Offline）。在胶片时代，离线剪辑可以保护原始底片在剪辑过程中不受影响。尽管在数字时代，我们已经可以实现基于原始素材的制作流程，但是使用离线剪辑流程，依旧有其独特的优势，对提升制作效率有很大的帮助。
