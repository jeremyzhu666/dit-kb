ARRI 摄影机实操

来源：小红书「酷卡学院 Academy KK」实战笔记汇编（ARRI 各机型主屏幕参数、格卡流程、目镜、读卡器固件与 HDE 编码。），2026-11-01 采集整理。

ARRI摄影机基础知识·主屏幕详解

（　👍 118）

来源：小红书「酷卡学院 Academy KK」／@酷卡DIT

01 主屏幕

尽管 ARRI mini 作为一台电影摄影机，操作却十分直观，目镜屏幕上下分布着六个按钮，可快速调整常用参数。 主屏显示：帧率（FPS）／时间码（TC）／快门（SHUTTER）；编码格式（如 ProRes 4444 HD 1920x1080 16:9）；录制状态（STBY 待机）；卷号 REEL（A001）、片段 CLIP（C000）、时长 DUR、存储卡剩余时间 CARD；电池电压 BAT；曝光指数 EI（800）、LOOK（ARRI 709）、白平衡 WB（5600K）。

02 帧率

此处调整的是拍摄帧率（Sensor FPS）。如果拍摄帧率高于项目帧率（Project Rate），称为升格拍摄，也就是俗称的慢动作拍摄。可选 23.976 / 24.000 / 25.000 / 29.970 等，界面会提示"项目帧率为 24p 时，结果为实时"。

03 时间码

时间码是一项重要的元数据。插入时码器后选择"自由运行-重生"（REC RUN - REGEN - MEDIA），在时码器 APP 上同步时间。

04 快门角度

和微单/单反不同，电影摄影机用快门角度表示快门速度。快门角度为 180 度时，单帧曝光时间为一帧时长的一半。可选 45.0 / 90.0 / 172.8 / 180.0 / 270.0，支持单位切换。

05 曝光指数 EI

EI 和 ISO 并不相同。Mini 的基准 ISO 为 800，EI 只影响监看亮度（具体知识可搜索 B 站家硕老师视频）。

06 画面风格

可调整拍摄画面/监看画面/输出画面的 Gamma/色彩空间/风格倾向，也可导入制作好的 LUT 实现基础的现场调色。如：LOOK ARRI 709；录制 Log C；取景器/翻转屏 Look；SDI Look。

07 白平衡

根据灯光环境不同，常见的白平衡有：钨丝灯 3200K、荧光灯 4300K、日光 5600K。白平衡高于色温偏暖，低于色温偏冷。

08 信息界面

拍摄界面显示的是最近一条素材编号。DIT 需要多关注存储卡剩余时间，如遇到即将拍满或是临近收工需提前换卡。

（　👍 128）

ARRI摄影机格卡分为：目镜格卡和机身格卡 一般情况下使用目镜格卡，在使用稳定器时，会取下目镜，需在机身上格卡

⚠️素材一旦格式化便很难恢复，请仔细确认素材已经安全双备份 ⚠️切勿使用WI-FI连接机身间接格卡，以免发生误格其他机器的情况

💡TIPS 1⃣️空卡插至电脑会显示ARRI_UDF 2⃣️如拍摄未格卡，ARRI会自动新建一个当前机器卷号的文件夹 3⃣️可关注卡槽上方指示灯，闪红灯为正在格卡，闪绿灯为完成格卡 4⃣️画面回放时，请勿拔卡 5⃣️插新卡后，建议回放确认卡内素材 6⃣️ARRI mini格卡需等待20-30秒 7⃣️通常情况一台mini配三张CFast 2.0 256G存储卡

Codex读卡器低性能提示如何更新固件？

（2024-03-17　👍 26）

  • 索尼 A7S3 ver3.00 固件支持通过 Micro USB（multi/micro USB 终端）输入时间码，无需再用音频方式输入时码。
  • 连接方式和 FX3/FX30 一致，使用谛听 C23 时码线即可。

Codex读卡器低性能提示如何更新固件？（65f66a3c，3 图）

  • 部分 Codex 读卡器连接电脑时提示"性能降低"：较老型号与 M1 芯片兼容性差，需更新固件。
  • 不兼容型号（macOS 12.4 或之后版本）：
    • Rev A（序列号 01052271 之前）：限 600MB/s
    • Rev B（01052272–01054999）：限 600MB/s，更新固件后满速
    • Rev C（01055000 之后）：满速
  • 序列号在读卡器底部铭牌（MODEL CX.0001005 旁 SERIAL NO.）。
  • 更新方法：官网下载安装 Codex Device Manager → 连接卡和读卡器 → 点齿轮图标 → Update Firmware → 固件更新工具点 Run → 完成后重新插拔设备，齿轮感叹号消失，速度提升。

ARRI RAW压缩编码HDE使用教程

（　👍 100）

  • 什么是 HDE：专为 ARRI RAW 设计的无损编码方式。拷贝时使用 HDE 可将原始文件体积缩小约 40%，提高拷贝效率、节省存储空间、降低存储成本。
  • 怎么用：Codex 存储卡插入读卡器 → 安装最新版 Codex Device Manager → Preferences → HDE 勾选 ARRIRAW → 电脑弹出两个盘符（如 A008ROPL 和 A008ROPL_hde），黑色盘符为 HDE 后素材。
  • 注意事项：HDE 文件显示 0KB，必须使用专业数据管理软件（如 Silverstack）才可正确拷贝。mini LF 的 HDE 文件无封装、为 .arx 序列帧；35 的 HDE 文件为 .mxf 封装。
  • 效果实测：使用前 814GB（58 files）→ 使用后 350GB（47371 files）。
  • CFast 卡：用 Codex 读卡器免费使用 HDE；第三方读卡器需单独购买许可。
  • 压缩只作用于 RAW 文件；卡里没有 RAW 文件则不弹出 HDE 盘符。
